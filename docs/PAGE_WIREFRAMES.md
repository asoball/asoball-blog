## 6. About / 404 / Empty
- About：窄版文字容器、作者介紹、關注領域、已設定的外部連結；不要求個人照片。
- 404：簡短標題、說明、回首頁/全部文章；使用全站 Header/Footer。
- Empty：頁面標題 +「目前沒有文章」+ 返回文章列表；不得顯示假文章。
